Рабочий репозиторий нового сайта [ivs-corp.ru](https://ivs-corp.ru).
Основа - утверждённый заказчиком **вариант 2 (светлый)** из репозитория прототипов [ivs-site-hero](https://github.com/koryaginstudio/ivs-site-hero).

GitHub: https://github.com/koryaginstudio/ivs-site

**Продолжение работы в новом чате: сначала открыть [HANDOFF.md](HANDOFF.md).** Там собраны контекст переписки, согласованные решения, карта кода и полный план оставшихся задач.

Стек: Next.js 16 (App Router) + React 19 + TypeScript, CSS-модули, токены дизайн-системы ИВС в `app/globals.css`.

## Запуск одной командой

Нужен Node.js 20.9 или новее.

```bash
npm run local
```

Сайт откроется на `http://localhost:7100/`. При первом запуске зависимости установятся автоматически, `.env.local` будет создан из `.env.example`. Без ключей Supabase сайт работает на локальных данных.

На Windows можно запустить `start.bat` двойным кликом. В Kimi достаточно команды **«включай локалку»** - она соответствует `npm run local`.

Другие команды:

```bash
npm run local -- --port 7101  # другой порт
npm run local -- --check      # проверка подготовки без сервера
npm run dev                   # обычный dev-запуск
npm run build && npm start    # production-сборка и запуск
```

## Правила

- Наполнение берём с ivs-corp.ru, меняем дизайн, не факты (`components/ivs-content.ts`).
- Логотип не перерисовываем, используем только готовые файлы из `public/`.
- Картинки в `public/` не перезаписывать под тем же именем из-за кэша Safari: новая версия = новое имя.
- Не добавлять формы обратной связи.
- Секреты и `.env.local` не коммитить.
- Перед коммитом: `npm run build` и `git diff --check`.
- Коммиты по-русски, осмысленно.
