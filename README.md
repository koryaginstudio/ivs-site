# ИВС-СЕТИ — новый сайт

Рабочий репозиторий нового сайта [ivs-corp.ru](https://ivs-corp.ru).
Основа — утверждённый заказчиком **вариант 2 (светлый)** из репозитория прототипов [ivs-site-hero](https://github.com/koryaginstudio/ivs-site-hero).

Стек: Next.js 16 (App Router) + React 19 + TypeScript, CSS-модули, токены дизайн-системы ИВС в `app/globals.css`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # продакшн-сборка
```

## Документы

- `docs/структура-сайта.md` — карта страниц и блоков публичной части.
- `docs/структура-админки.md` — состав административной панели.
- `docs/дизайн-система.md` — токены и правила дизайн-системы ИВС.

## Правила

- Наполнение берём с ivs-corp.ru, меняем дизайн, не факты (`components/ivs-content.ts`).
- Логотип не перерисовываем — только готовые файлы из `public/`.
- Картинки в `public/` не перезаписывать под тем же именем (кэш Safari) — новая версия = новое имя.
- Коммиты по-русски, осмысленно.
