# ИВС-СЕТИ - новый сайт

Рабочий репозиторий нового сайта [ivs-corp.ru](https://ivs-corp.ru).
Основа - утверждённый заказчиком **вариант 2 (светлый)** из репозитория прототипов [ivs-site-hero](https://github.com/koryaginstudio/ivs-site-hero).

GitHub: https://github.com/koryaginstudio/ivs-site

**Продолжение работы в новом чате: сначала открыть `AGENTS.md`, `HANDOFF.md` и документы в `docs/`.** Там собраны правила синхронизации, согласованные решения, карта кода и оставшиеся задачи.

Стек: Next.js 16 (App Router) + React 19 + TypeScript, CSS-модули, токены дизайн-системы ИВС в `app/globals.css`.

## Запуск после клонирования

Нужен Node.js 20.9 или новее и доступ к приватному GitHub-репозиторию.

```bash
git clone https://github.com/koryaginstudio/ivs-site.git
cd ivs-site
npm run local
```

Сайт откроется на `http://localhost:7100/`. При первом запуске зависимости установятся автоматически, `.env.local` будет создан из `.env.example`, Git-хуки подключатся. Без ключей Supabase сайт использует полный локальный снимок контента, дополнительная настройка БД не нужна.

На Windows можно запустить `start.bat` двойным кликом. В Kimi достаточно команды **«включай локалку»** - она соответствует `npm run local`.

Другие команды:

```bash
npm run local -- --port 7101  # другой порт
npm run local -- --check      # проверка подготовки без сервера
npm run dev                   # обычный dev-запуск
npm run build && npm start    # production-сборка и запуск
```

## Автоматическая синхронизация с GitHub

`npm run local` и установка зависимостей запускают `scripts/install-git-hooks.mjs`, который задаёт `core.hooksPath=.githooks`. После каждого коммита `.githooks/post-commit` автоматически отправляет текущую ветку в `origin`.

Правило для любого ИИ записано в `AGENTS.md`: после каждой завершённой пользовательской задачи выполнить проверки, создать осмысленный русский коммит и убедиться, что он ушёл на GitHub. Изменения отправляются после коммита, а не после каждого сохранения отдельного файла. При ошибке сети коммит остаётся локально, хук выводит команду для повторной отправки.

Проверить или подключить хуки вручную:

```bash
node scripts/install-git-hooks.mjs
git config --get core.hooksPath
```

## Правила

- Наполнение берём с ivs-corp.ru, меняем дизайн, не факты (`components/ivs-content.ts`).
- Логотип не перерисовываем, используем только готовые файлы из `public/`.
- Картинки в `public/` не перезаписывать под тем же именем из-за кэша Safari: новая версия = новое имя.
- Не добавлять формы обратной связи.
- Секреты и `.env.local` не коммитить.
- Перед коммитом: `npm run build` и `git diff --check`.
- Коммиты по-русски, осмысленно.
