## Анимации 🟢

Принципы из ДС-артефакта, подтверждены утверждённым вариантом 2.

- Анимируем только transform / opacity / цвет. Никакого `transition: all`.
- Тайминги: press 160ms, fast 200ms, base 250ms, enter 500ms; каскад появления 60ms.
- Кривые: `--ease-out` `cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out` `cubic-bezier(0.77,0,0.175,1)`, hover-приближение `cubic-bezier(0.22,1,0.36,1)` 600ms.
- Hover-эффекты только для мыши (`@media (hover: hover) and (pointer: fine)`).
- `prefers-reduced-motion` — уважаем: появление сводится к fade, трансформации отключаются.
- Производительность (Safari): на движущихся слоях никаких `filter: blur()`, SVG-фильтров и масок — движение только через transform.
