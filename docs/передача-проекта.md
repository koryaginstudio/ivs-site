## 1. Как продолжить на другом компьютере

1. Открыть Kimi и авторизоваться в GitHub тем же аккаунтом `koryaginstudio`.
2. Склонировать проект:

```bash
git clone https://github.com/koryaginstudio/ivs-site.git
cd ivs-site
```

3. Открыть папку `ivs-site` как рабочую папку Kimi.
4. Дать Kimi команду: `Прочитай HANDOFF.md, README.md и все документы в docs. Продолжай проект с текущего состояния`.
5. Для запуска сайта дать команду: `включай локалку`.

Эквивалентная команда терминала:

```bash
npm run local
```

Скрипт сам проверит Node.js, установит зависимости при первом запуске, создаст пустой `.env.local` из примера и запустит сайт на `http://localhost:7100/`. На Windows можно запустить `start.bat` двойным кликом.

Требования: Node.js 20.9 или новее, рекомендован актуальный LTS. Ключи Supabase для локального макета не нужны: без них работают локальные снимки новостей и проектов.

Полезные команды:

```bash
npm run local -- --port 7101  # если порт 7100 уже занят
npm run local -- --check      # проверить подготовку без запуска сервера
npm run dev                   # обычный dev-запуск Next.js
npm run build                 # production-сборка и проверка TypeScript
npm start                     # запуск готовой production-сборки
git pull                      # получить последнюю версию перед работой
git status                    # проверить локальные изменения
```

## 2. Коротко: что это за проект

Разрабатывается новый корпоративный сайт ИВС-СЕТИ. Заказчик выбрал светлый вариант главного экрана номер 2. Этот репозиторий выделен из репозитория прототипов и предназначен для готового дизайна и дальнейшей разработки, а не для новых концептов hero.

Сейчас реализована интерактивная главная страница от шапки до футера. Это ещё не готовый к публикации сайт: внутренние страницы, поиск, админка, реальная запись в БД, аналитика и production-инфраструктура не реализованы.

Текущий порядок главной:

```text
Шапка и Hero
→ Направления деятельности
→ О компании
→ Услуги
→ Проекты
→ Партнёры
→ Новости и мероприятия
→ Контакты
→ Футер
→ Cookie-уведомление
```

Стек: Next.js 16.4.6, React 19, TypeScript, CSS Modules, App Router, Supabase-ready слой данных. Стили и контент не надо переносить на другую библиотеку без причины.

## 4. Подтверждённые требования и решения

### Бренд и визуальный язык

- Выбран светлый вариант 2, утверждён 19.10.2026.
- Брендбука у компании нет, есть логотип и собранная нами дизайн-система.
- Основной акцент `#d83437`, нажатие `#b5282b`, глубокий красный `#88130c`.
- Основной текст `#1f1e1e`, вторичный `#5c5a5a`, фоны `#ffffff` и `#f4f4f4`.
- Шрифт только Inter. Без засечек, рукописных и художественных шрифтов.
- Не использовать яркие заливки целых страниц. Красный - точечный акцент, кроме специально заложенной акцентной панели.
- Не перерисовывать логотип. Слоган рядом со знаком в шапке не добавлять.
- Выделение текста на сайте фирменное красное, не стандартное синее.
- Один заголовок у секции, без дополнительных надзаголовков-eyebrow.
- Формулировки заголовков спокойные и близкие к текущему сайту, без придуманной рекламной напыщенности.
- Вертикальный ритм секций 64 px, на mobile 32 px. Не ставить две обычные белые контентные секции подряд. Скруглённые панели hero, «О компании» и контакты - отдельный тип композиции.
- Уважать `prefers-reduced-motion`. Hover-анимации только для устройств с мышью.

### Шапка и навигация

- Логотип, основное меню, открытая поисковая строка и телефон.
- Вместо иконки-лупы сделана открытая строка между меню и телефоном. Это согласованное визуальное решение, но сам поиск ещё не работает.
- Кнопка «Заказать звонок» убрана. Заказчик исключил формы обратной связи, связь через телефон, почту и контакты.
- Мега-меню услуг содержит 8 официальных направлений и 30 подуслуг.
- Партнёры пока находятся внутри меню «Компания». Отдельный пункт первого уровня остаётся открытым вопросом.
- Продукты ведут на внешний Link для ВКС.

### Главная страница

- Hero сохраняет утверждённую композицию варианта 2: заголовок «Полный комплекс ИТ-услуг для бизнеса и госсектора», описание, кнопки услуг и проектов, цифры, 3D-иллюстрация.
- Текущая иллюстрация hero тестовая. Финальную нужно подготовить и показать отдельно.
- Направления деятельности оформлены карточками: слева квадратное медиа 1:1 под 3D-иконку без фона, справа заголовок, стрелка в правом верхнем углу.
- Текущая рабочая версия содержит 11 отраслевых карточек и спрайтовые вращения иконок. Этот состав и анимацию Антон должен проконтролировать отдельно, они не считаются финально утверждёнными.
- «Услуги» перенесены в отдельный блок сразу после «О компании» 21.11.2026.
- В услугах слева аккордеон из 8 направлений, справа видео-preview. Hover и focus меняют видео, клик и Enter раскрывают подуслуги, повторный клик закрывает панель.
- Видео услуг сделаны из реальных проектных фото ИВС, без случайных стоков. Это временные motion-preview, при наличии съёмки файлы заменяются без изменения механики.
- Проекты - реальные карточки с фото 1:1, отраслью, годом и описанием. Под ними лента лет со счётчиками вместо select старого сайта.
- Партнёры всегда цветные. При hover логотип немного приближается, чёрно-белой механики больше нет.
- В ленте 61 официальный вендор. Первый экран содержит выбранные Антоном логотипы, остальные идут официальным списком. Сетка 5 × 3, на mobile 3 колонки, есть свайп, стрелки и счётчик.
- Новости и мероприятия - карточки с фото 4:3 и реальными материалами ИВС. Формулировка 3:4 в переписке была уточнена как горизонтальное фото, реализовано 4:3.
- Контактный блок содержит телефон, почту и адрес, без формы.
- В футере есть отдельная колонка «Документы», реальные ссылки, автоматический копирайт © 1990–текущий год. ИНН и КПП из нижней строки убраны.
- Cookie-плашка классическая, без лишних эффектов: «Только необходимые», «Принять все», ссылка на `/cookie/`, выбор хранится локально 180 дней.

- Большинство карточек и пунктов меню пока ведут на существующий `ivs-corp.ru`, а не на локальные внутренние страницы. Это осознанная временная мера, не финальное поведение.

### Данные

- `lib/news-seed.ts` - 18 реальных материалов, снимок от 20.11.2026.
- `lib/projects-seed.ts` - 20 реальных проектов, снимок от 20.11.2026.
- `lib/news.ts` и `lib/projects.ts` - серверный слой чтения: Supabase при заполненных ключах, локальный снимок при их отсутствии или ошибке.
- `supabase/migrations/0001_news.sql` - таблица новостей и начальное наполнение.
- `supabase/migrations/0002_projects.sql` - таблица проектов и начальное наполнение.
- Главная ревалидируется раз в 300 секунд, чтобы опубликованные материалы появлялись без полной пересборки.
- Сейчас реализовано только чтение карточечных данных. Полные тексты статей и кейсов, CRUD, загрузка медиа, пользователи и запись из админки отсутствуют.
- Мероприятия с Tilda ещё не импортированы в таблицу `news`.

- Production-сборка проходила после блока услуг.
- Интерактивный блок услуг проверен на всех 8 направлениях: hover, click, Enter, закрытие, 30 ссылок, одно видео в DOM и reduced-motion.
- Проверены desktop 1440 px и mobile 375 px для блока услуг, отсутствие горизонтального переполнения на 375 px.
- Предыдущие проверки не заменяют финальное регрессионное тестирование всего сайта на всех контрольных ширинах.

Правила работы с кодом:

- Не менять факты компании без источника.
- Не менять утверждённый hero на другую концепцию.
- Не вводить новые цвета и шрифты вне дизайн-системы.
- Не перерисовывать логотип.
- Не перезаписывать изображение под тем же именем из-за кэша Safari, новая версия получает новое имя.
- Не оставлять dev-серверы и временные проверочные скрипты без необходимости.
- Перед коммитом выполнить `npm run build` и `git diff --check`.
- Не смешивать чужие параллельные изменения в один коммит без необходимости. На момент передачи все актуальные файлы специально сохранены вместе по просьбе Антона.
- Коммиты делать осмысленными и по-русски.
