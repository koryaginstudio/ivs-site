## Блоки главной страницы

1. **Hero** 🟢 — заголовок «Полный комплекс ИТ-услуг для бизнеса и госсектора», описание, кнопки «Все услуги» / «Реализованные проекты», 3 карточки с цифрами (1400+ проектов, 200+ специалистов, с 1990 года), 3D-иллюстрация. Утверждён вариантом 2 (19.10). 🟡 иллюстрация тестовая, финальную заменим.
2. **Направления деятельности** 🟢 — 6 карточек с красными линейными иконками. Утверждено вариантом 2.
3. **О компании коротко** 🔴 — заголовок «О компании», абзац, цифры (480 сотрудников, 1447 проектов, 6000 заказчиков), ссылка на /company/.
4. **Избранные проекты** 🔴 — нумерованный список 6 проектов с тегами, ссылка на каталог.
5. **Новости и мероприятия** 🔴 — лента последних 3 материалов.
6. **Партнёры** 🟢 — сетка 3×3 официальных логотипов (Microsoft, Acer, Adobe, МойОфис, Касперский, 1С, Dr.Web, D-Link, Positive Technologies), выборка и порядок — Антон, 20.11. Ч/б по умолчанию, цвет при наведении.
7. **Контактный блок** 🔴 — телефон, почта, адрес. 🟢 формы обратной связи нет (письмо 24.09).
8. **Футер** 🟢 — меню разделов, контакты, реквизиты, колонка «Документы» (5 документов заглушками — решено 20.11), копирайт © 1990–текущий год (год меняется автоматически — решено 20.11).

Блоки 1-2 сделаны и утверждены. Блоки 3-8 — мой состав, сам факт наличия разделов согласован, но наполнение главной с заказчиком не обсуждалось.
