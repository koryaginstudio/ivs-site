# Дизайн-система лендинга ИВС (v2, светлый вариант)

Внутренний документ - фиксирует визуальный язык утверждённого hero и карточек, чтобы собирать остальные блоки без артефактов. Канон значений - `app/globals.css` (токены) и `app/home.module.css` (паттерны v2). Новые токены не вводить без нужды.

## 1. База

| Параметр | Значение |
|---|---|
| Фон страницы | `--surface-100` #ffffff |
| Фон панелей/карточек-заливок | `--surface-200` #f4f4f4 |
| Основной текст | `--Dark_text_elements` #1f1e1e |
| Вторичный текст | `--text-muted` #5c5a5a |
| Акцент | `--red_main` #d83437 |
| Акцент при наведении/нажатии | `--red_pressed` #b5282b |
| Глубокий красный (градиенты) | `--red_deep` #88130c |
| Тонкие рамки (hairline) | #e9e7e7 - только как локальный `--hairline` в home.module.css |
| Разделители плотнее | `--line` #d4d2d2 |
| Шрифт | Inter, 400/500/600/700. Без засечек, без рукописных |

Правило акцента: красный - это «краска», а не «цвет интерфейса». Основа всегда белая/светло-серая, красным - иконки, цифры, кнопки, активные состояния, линии-подчёркивания. Заказчик просил без ярких заливок страниц.

## 2. Типографика

| Роль | Стиль |

| Заголовок секции | 700, clamp(24–34px) / 1.15, −0.015em. Единственный заголовок блока - надзаголовки (eyebrow с индексами) запрещены, правило 20.11 |
| Заголовок mega-меню | 700, 24/32, −0.01em |
| Подзаголовок блока | 600, 19/26 |
| Лид/подводка | 400, 19/30, `--text-muted`, max-width 46ch |
| Заголовок карточки | 600, 18/26, balance |
| Текст карточки, пункты меню | 400–500, 15/22–20 |
| Подписи, мелкий текст | 400, 14/20, `--text-muted` |

Иерархия - размером и весом в диапазоне 400–700, не толщиной заголовков выше 700.

## 3. Геометрия

- Сетка: шаг 8px (`--space-*`: 4/8/16/24/32/48/80/120). Контент max-width 1440px, боковые поля `--gutter` = clamp(16px, 4vw, 56px).
- Ритм секций: без внешних `margin`, у каждой секции одинаковый вертикальный `padding` 64px на desktop/tablet и 32px на ≤640px. Перед футером дополнительный отступ не добавляется.
- Фоны чередуются на всю ширину окна: обычные секции `--surface-100`, услуги и партнёры `.sectionMuted` на `--surface-200`, проекты и новости белые. Две белые контентные секции подряд не ставить. Скруглённые hero, «О компании» и контакты остаются отдельными панелями на белом фоне.
- Радиусы: карточки/панели - 20px; крупные плашки (hero) - 28px; кнопки/поля - 12px; мелкие элементы (chip, стрелка) - 8px; пилюля - 999px. (Токены: 8/12/20/28.)
- Линии: рамки 1px `--hairline`; подчёркивания кнопок 1.5px.

## 4. Компоненты

### Плашка-hero (`.panel`)
- Светлая: заливка `--surface-200`, радиус 28px, внутренний padding 64px (desktop) → 48/32 по мере сжатия, вся страница белая вокруг.
- Акцентная (`.panelAccent`): радиальный градиент `118% 123% at 50% −23%`: #ffffff → #f04a55 41% → #c8121e 72% → #8a0b12. Белый текст, розовый акцент заголовка #ffd2d5, свечение - белое.
- На акцентной: основная кнопка белая (текст #1f1e1e), вторая - стекло rgba(255,255,255,0.1), цифры - стекло с blur 16px, при наведении белеют, цифра становится красной.

### Кнопки (`.btn`)
- Высота 60px (mobile 52px), радиус 16px (mobile 12), padding слева 18px, справа 32px, gap 14px.
- Слева квадрат-иконка 26px, радиус 8px, подложка rgba(255,255,255,0.18) у красной / `--surface-200` у белой.
- Primary: заливка `--red_main`, белый текст; hover → `--red_pressed` + подъём translateY(−2px) + тонкая линия снизу из центра (`.btn::after`, 300ms).
- Secondary: белый фон, рамка `--hairline`, тёмный текст; hover → рамка `--line`.
- На акцентной плашке правила инвертируются (см. выше).
- Нажатие: scale(0.98), 160ms. Никаких форм обратной связи - только ссылки.

### Шапка
- Sticky, белая, нижняя граница `--hairline`. Логотип 44px. Пункты меню: min-height 44px, padding 12px, радиус 8, 500 15/20. Активный пункт меню/открытая панель - красный текст.
- Плавающая подложка под меню: 40px высота, радиус 12, `--surface-200`, перетекает 450ms `ease-hover`.
- Поиск - открытая строка между меню и телефоном (не иконка-лупа): тянется `flex: 1` до max 440px, высота 44px, радиус 12, рамка `--hairline`, лупа 20px слева, focus → рамка `--line-strong`. На ≤1100px скрыта. Механика поиска не подключена.
- CTA-кнопки в шапке нет: «Заказать звонок» убрана по требованию заказчика (обратная связь исключена, 24.09). Связь - телефон в шапке и страница контактов.

### Логотипы партнёров (`.partnerTrack`, `.partnerGrid`)
- 61 официальный вендор из `/public/partners`, список соответствует ivs-corp.ru/company/partners/. Первые 15 позиций закреплены в согласованном порядке, остальные следуют официальному списку. Для слабых исходников использованы SVG или качественные PNG, поля обрезаны по контенту.
- Лента из 5 экранов по 15 позиций (на последнем 1): `overflow-x: auto`, `scroll-snap-type: x mandatory`, скрытый scrollbar. Поддержаны свайп, стрелки 44×44px и счётчик страниц; на первом экране нет стрелки назад, на последнем - вперёд.
- Сетка экрана 5 столбцов × 3 ряда на desktop/tablet, на ≤640px - 3 колонки. Без рамок и подложек, ячейка min-height 88px (mobile 72px).
- Основной логотип: контейнер 150×42px (mobile 100×32px), max-width 100%, `object-fit: contain`. Вертикальные знаки с `compact` получают 110×52px (mobile 76×40px) для равного оптического веса.
- Логотип всегда цветной. Hover только на мыши: `scale(1.08)` за 600ms `--ease-hover`. Ч/б-фильтра и прозрачности нет, в reduced-motion трансформация и плавный scroll отключены.

### Медиа-карточки: проекты (`.projCard`) и новости (`.newsCard`)
- Одинаковый каркас: белая, рамка `--hairline`, радиус 20, padding 16 (снизу 64 под стрелку). Стрелка 32px на `--surface-200` в правом нижнем углу, hover - красная с белой иконкой и сдвигом (3px, −3px).
- Фото сверху, радиус 12, на сером `--surface-200` (плейсхолдер, если фото нет): у проектов 1:1, у новостей 4:3. Всегда `object-fit: cover` - исходники любых пропорций не ломают сетку. Hover - scale(1.05) за 600ms.
- Текстовый блок: мета-строка (пилюля отрасли/тип + год/дата), заголовок 600 16-17px (clamp 3 строки), описание 400 14px muted (clamp 2 строки). Если описания нет - не выводится, карточка не проседает.
- Hover карточки: рамка rgba(216,52,55,0.3), тень `--shadow-3`, подъём translateY(−6px) scale(1.02).
- Сетки: 3 колонки desktop, 2 на ≤940px, 1 на ≤640px.

### Лента лет (`.yearRail`) - календарная механика проектов
- Под сеткой карточек, отбита сверху hairline. Подпись «Проекты по годам:» + пилюли лет.
- Пилюля 40px, радиус full, рамка `--hairline`, год + счётчик проектов (12px, opacity 0.55). Активная - заливка `--red_main`, белый текст; hover активной - `--red_pressed`.
- На ≤640px - горизонтальная прокрутка без видимого скроллбара, пилюли не жмутся.
- Фильтрация мгновенная на клиенте (данные приходят сервером из слоя БД), смена года - fade сетки 300ms.

### Карточки направлений (`.card` + `IndustryCards.module.css`)
- Белые, рамка `--hairline`, радиус 20, padding 24. Горизонтальная раскладка: слева медиа 1:1 (104px, на ≤640px - 88px), справа заголовок 600 18/26 и стрелка 32px в правом верхнем углу.
- Текущая рабочая версия содержит 11 отраслевых карточек с 3D-иконками без фона. Этот состав не считать согласованным без контроля Антона. На ≤640px сетка строго `minmax(0, 1fr)`, чтобы длинные названия не растягивали viewport.
- При hover/focus 3D-иконка плавно приближается и проигрывает один поворот через спрайт, при reduced-motion остаётся статичной. Карточка поднимается только на 2px, без сильного увеличения.

### Каталог услуг (`Services.module.css`)
- Отдельная серая секция сразу после «О компании». Сетка примерно 55/45: слева список-аккордеон из 8 официальных направлений, справа sticky preview 16:10. Решение согласовано Антоном 21.11.
- Строка: индекс 12px, название 600 clamp(18–24px) / 1.3, круглая кнопка 32px. Активная строка получает белую подложку через `scaleY`, красный индекс и сдвиг текста 6px, без тяжёлой тени. Раскрытие - `grid-template-rows: 0fr → 1fr` за 400ms, плюс поворачивается в крест.
- Подуслуги: 400 14px / 1.5, muted; отдельная красная ссылка «Открыть направление». Скрытые ссылки получают `tabIndex=-1`. Enter и фокус работают наряду с hover и кликом.
- В DOM одно видео: muted, loop, playsInline, preload metadata, poster из того же проектного фото. При смене направления - проявление и scale за 420ms. Под видео название направления, число подуслуг и проектная подпись.
- Все 8 WebM созданы локально из реальных фото каталога проектов ИВС, размер 960×600, длительность 4,8 секунды, без звука. Скрипт воспроизводимости - `scripts/generate-service-previews.mjs`. Случайные стоковые ролики запрещены.
- На ≤940px сетка одноколоночная, preview первым и не sticky. При reduced-motion autoplay и трансформации отключены, виден poster.

### Cookie-плашка (`.cookieBar`) и статичные страницы (`.staticPage`)
- Плашка фиксирована снизу по центру: ширина min(920px, 100vw − 32px), белый фон, рамка `--hairline`, радиус 20, `--shadow-3`, padding 24. Появление - мягкое cookieIn 400ms с задержкой 500ms.
- Desktop: текст слева, две кнопки справа. Mobile: колонка, основная кнопка «Принять все» сверху, «Только необходимые» снизу, обе на всю ширину. Выбор хранится локально 180 дней.
- `/cookie/`: контент max-width 860px, боковые поля `--gutter`, H1 700 clamp(28–40px), карточки категорий в 2 колонки и 1 колонку на ≤640px.

### Карточки-цифры (`.stat`)
- Белые, радиус 20, shadow-1. Цифра красная. Hover: заливается `--red_main`, цифра белая scale(1.08), тень `--shadow-brand`, 600ms.

### Тени
- `--shadow-1`: карточки покоя. `--shadow-3`: выпадающие панели, hover карточек. `--shadow-brand`: красные hover. Никаких тяжёлых чёрных теней.

## 5. Движение

| Токен | Значение |
|---|---|
| `--dur-hover` | 600ms - главный «приближающий» hover |
| `--ease-hover` | cubic-bezier(0.22, 1, 0.36, 1) |
| `--duration-fast` | 200ms - фоны, цвета |
| `--duration-press` | 160ms - нажатия |
| Каскад появления | 600ms rise + 60ms stagger на элемент |

Hover-эффекты - только `@media (hover: hover) and (pointer: fine)`. При `prefers-reduced-motion` - всё гаснет в простые переходы.

## 6. Адаптивные точки

960 / 1100 / 1280 / 640 (mobile). Проверка ширин: 375 / 720 / 960 / 1280 / 1440 / 1920, без горизонтальной прокрутки.

## 7. Запреты (чтобы не артефачить)

- Не вводить новые цвета вне палитры выше; оттенки красного только из `--red_main/-pressed/-deep/light` и градиента плашки.
- Не делать залитые красным секции кроме `.panelAccent`; красный - точечный акцент.
- Не использовать тени кроме токенов; не использовать чёрный (#000) вообще - только #1f1e1e.
- Не дробить интерфейс мелкими радиусами: 8 - только для chip/мелочей, 12 - кнопки, 20 - карточки, 28 - hero.
- Не добавлять формы обратной связи (согласовано с заказчиком убрать).
- Не добавлять надзаголовки (eyebrow с индексами вида «05 НОВОСТИ») - один заголовок на секцию (правило Антона, 20.11).
- Не вставлять сервисные пометки (типа «иллюстрация тестовая») на страницы - это dev-артефакт.
