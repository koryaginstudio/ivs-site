# Дизайн-система лендинга ИВС (v2, светлый вариант)

Внутренний документ - фиксирует визуальный язык утверждённого hero и карточек, чтобы собирать остальные блоки без артефактов. Канон значений - `app/globals.css` (токены) и `app/home.module.css` (паттерны v2). Новые токены не вводить без нужды.

## 1. База

| Параметр | Значение |
|---|---|
| Фон страницы | `--surface-100` #ffffff |
| Фон панелей/карточек-заливок | `--surface-200` #f4f4f4 |
| Основной текст | `--Dark_text_elements` #1f1e1e |
| Вторичный текст | `--text-muted` #5c5a5a |
| Акцент | `--red_main` #d83437 |
| Акцент при наведении/нажатии | `--red_pressed` #b5282b |
| Глубокий красный (градиенты) | `--red_deep` #88130c |
| Тонкие рамки (hairline) | #e9e7e7 - только как локальный `--hairline` в home.module.css |
| Разделители плотнее | `--line` #d4d2d2 |
| Шрифт | Inter, 400/500/600/700. Без засечек, без рукописных |

Правило акцента: красный - это «краска», а не «цвет интерфейса». Основа всегда белая/светло-серая, красным - иконки, цифры, кнопки, активные состояния, линии-подчёркивания. Заказчик просил без ярких заливок страниц.

## 3. Геометрия

- Сетка: шаг 8px (`--space-*`: 4/8/16/24/32/48/80/120). Контент max-width 1440px, боковые поля `--gutter` = clamp(16px, 4vw, 56px).
- Радиусы: карточки/панели - 20px; крупные плашки (hero) - 28px; кнопки/поля - 12px; мелкие элементы (chip, стрелка) - 8px; пилюля - 999px. (Токены: 8/12/20/28.)
- Линии: рамки 1px `--hairline`; подчёркивания кнопок 1.5px.

## 4. Компоненты

### Плашка-hero (`.panel`)
- Светлая: заливка `--surface-200`, радиус 28px, внутренний padding 64px (desktop) → 48/32 по мере сжатия, вся страница белая вокруг.
- Акцентная (`.panelAccent`): радиальный градиент `118% 123% at 50% −23%`: #ffffff → #f04a55 41% → #c8121e 72% → #8a0b12. Белый текст, розовый акцент заголовка #ffd2d5, свечение - белое.
- На акцентной: основная кнопка белая (текст #1f1e1e), вторая - стекло rgba(255,255,255,0.1), цифры - стекло с blur 16px, при наведении белеют, цифра становится красной.

### Кнопки (`.btn`)
- Высота 60px (mobile 52px), радиус 16px (mobile 12), padding слева 18px, справа 32px, gap 14px.
- Слева квадрат-иконка 26px, радиус 8px, подложка rgba(255,255,255,0.18) у красной / `--surface-200` у белой.
- Primary: заливка `--red_main`, белый текст; hover → `--red_pressed` + подъём translateY(−2px) + тонкая линия снизу из центра (`.btn::after`, 300ms).
- Secondary: белый фон, рамка `--hairline`, тёмный текст; hover → рамка `--line`.
- На акцентной плашке правила инвертируются (см. выше).
- Нажатие: scale(0.98), 160ms. Никаких форм обратной связи - только ссылки.

### Шапка
- Sticky, белая, нижняя граница `--hairline`. Логотип 44px. Пункты меню: min-height 44px, padding 12px, радиус 8, 500 15/20. Активный пункт меню/открытая панель - красный текст.
- Плавающая подложка под меню: 40px высота, радиус 12, `--surface-200`, перетекает 450ms `ease-hover`.
- Поиск - открытая строка между меню и телефоном (не иконка-лупа): тянется `flex: 1` до max 440px, высота 44px, радиус 12, рамка `--hairline`, лупа 20px слева, focus → рамка `--line-strong`. На ≤1100px скрыта. Механика поиска не подключена.
- CTA-кнопки в шапке нет: «Заказать звонок» убрана по требованию заказчика (обратная связь исключена, 24.09). Связь - телефон в шапке и страница контактов.

### Логотипы партнёров (`.partnerGrid`)
- Сетка 3×3 (на ≤640px - 2 колонки), без рамок и подложек, ячейка min-height 104px.
- Логотип: max-height 48px, max-width 72% ячейки, по умолчанию `grayscale(1)` + opacity 0.5; hover (только мышь) → цвет + opacity 1, 200ms.
- Только официальные логотипы из `/public/partners` (сняты с ivs-corp.ru/company/partners/).

### Карточки направлений (`.card`)
- Белые, рамка `--hairline`, радиус 20, padding 24/32/32 (mobile 24).
- Иконка - красная линейная на белом, без подложки. Стрелка 32px на `--surface-200`.
- Hover (только мышь): рамка rgba(216,52,55,0.3), тень `--shadow-3`, подъём translateY(−6px) scale(1.03), иконка scale(1.15), стрелка становится красной с белой иконкой и сдвигом (3px, −3px). Всё на 600ms `--ease-hover`.

### Карточки-цифры (`.stat`)
- Белые, радиус 20, shadow-1. Цифра красная. Hover: заливается `--red_main`, цифра белая scale(1.08), тень `--shadow-brand`, 600ms.

### Тени
- `--shadow-1`: карточки покоя. `--shadow-3`: выпадающие панели, hover карточек. `--shadow-brand`: красные hover. Никаких тяжёлых чёрных теней.

## 5. Движение

| Токен | Значение |
|---|---|
| `--dur-hover` | 600ms - главный «приближающий» hover |
| `--ease-hover` | cubic-bezier(0.22, 1, 0.36, 1) |
| `--duration-fast` | 200ms - фоны, цвета |
| `--duration-press` | 160ms - нажатия |
| Каскад появления | 600ms rise + 60ms stagger на элемент |

Hover-эффекты - только `@media (hover: hover) and (pointer: fine)`. При `prefers-reduced-motion` - всё гаснет в простые переходы.

## 6. Адаптивные точки

960 / 1100 / 1280 / 640 (mobile). Проверка ширин: 375 / 720 / 960 / 1280 / 1440 / 1920, без горизонтальной прокрутки.

## 7. Запреты (чтобы не артефачить)

- Не вводить новые цвета вне палитры выше; оттенки красного только из `--red_main/-pressed/-deep/light` и градиента плашки.
- Не делать залитые красным секции кроме `.panelAccent`; красный - точечный акцент.
- Не использовать тени кроме токенов; не использовать чёрный (#000) вообще - только #1f1e1e.
- Не дробить интерфейс мелкими радиусами: 8 - только для chip/мелочей, 12 - кнопки, 20 - карточки, 28 - hero.
- Не добавлять формы обратной связи (согласовано с заказчиком убрать).
- Не добавлять надзаголовки (eyebrow с индексами вида «05 НОВОСТИ») - один заголовок на секцию (правило Антона, 20.11).
- Не вставлять сервисные пометки (типа «иллюстрация тестовая») на страницы - это dev-артефакт.
